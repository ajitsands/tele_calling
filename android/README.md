# Android Companion Gateway Setup Guide

This lightweight Android companion app enables 5+ Android smartphones with different OS versions (Android 9 to Android 15) to stream telephony events (incoming/outgoing calls, phone numbers, state transitions, audio recordings) directly to your local PHP MVC server over Wi-Fi.

## Key Features
1. **Low-Latency Call Detection**: Hooks into `TelephonyManager` to push `RINGING` within 100ms over local Wi-Fi.
2. **Foreground Service**: Ensures background battery optimization doesn't kill the tracking service.
3. **Automatic Recording Sync**: Identifies call audio files generated by built-in dialers (Samsung, Xiaomi, OnePlus, Vivo, Oppo) and uploads them to `storage/recordings/`.
4. **Heartbeat & Battery Monitoring**: Informs the web portal about device battery and online status.

## Installation & Configuration
1. Build the APK using Android Studio or `./gradlew assembleDebug`.
2. Install the APK on each telecaller smartphone.
3. Connect the phone to the **same Wi-Fi network** as the server.
4. Launch the app and enter the server URL (e.g., `http://192.168.1.100:8000`).
5. Grant permissions:
   - **Phone & Call Logs**: Needed to read caller number and call state.
   - **Audio / Storage**: Needed to sync call recordings.
   - **Ignore Battery Optimizations**: Needed to maintain persistent service in the background.
6. Press **"Connect & Start Service"**. The device will register in the portal under **Devices & Shifts**.
